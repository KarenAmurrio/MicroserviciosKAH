# Sistema de Gestión de RRHH - Microservicios

Este proyecto implementa un sistema distribuido con arquitectura de microservicios para la materia de Ingeniería en Ciencia de la Computación (**USFX**).

## 🚀 Tecnologías utilizadas
* **Servicio Empleados:** Node.js, Express, MySQL (REST API).
* **Servicio Proyectos:** Apollo Server, MongoDB (GraphQL).
* **Orquestación:** Docker y Docker Compose.
